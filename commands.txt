Push to DockerHub:
    docker build -t ampyfin:3.01 .
    docker tag ampyfin:3.01 shepherd5pie0/repo:3.01
    docker push shepherd5pie0/repo:3.01

    All together: docker build -t anthropic . && docker tag anthropic shepherd5pie0/repo:anthropic && docker push shepherd5pie0/repo:anthropic

Run terminal in container:
    docker exec -it ampyfin-rank /bin/sh

To set up fresh instance:
    COMPOSE_PROFILES=setup,mongo docker compose up
    ...ensure training data is present at ../training-data/training_results.json on the container
    ...ensure TRAIN_MODE in .env is set to "push"
    COMPOSE_PROFILES=train,mongo docker compose up

To see first set of logs:
    docker logs CONTAINER_NAME 2>&1 | head -n X (where X is the number of logs)

To see recent logs:
    docker logs -f --tail 100 CONTAINER_NAME
